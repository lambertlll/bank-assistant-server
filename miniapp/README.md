# 银行助手小程序

## 功能

- 客户尽调（企业/个人）
- 财报分析（详细版/简化版）
- 审贷会助手

## 配置

### 1. 修改服务器地址

编辑 `miniapp/app.js`，修改 `apiBaseUrl`：

```javascript
App({
  globalData: {
    // 修改为你的服务器地址
    apiBaseUrl: 'http://your-server-ip:3000'
    // 如果配置了域名，使用：
    // apiBaseUrl: 'https://api.your-domain.com'
  }
});
```

### 2. 配置服务器域名白名单

在微信小程序后台配置服务器域名：

1. 登录 [微信公众平台](https://mp.weixin.qq.com/)
2. 进入"开发" → "开发管理" → "开发设置"
3. 找到"服务器域名"
4. 添加你的服务器域名到 **request合法域名**

**注意**：
- 必须使用 HTTPS（除非是开发环境）
- 域名必须备案
- 开发环境可以在微信开发者工具中勾选"不校验合法域名"

## 开发

### 1. 安装微信开发者工具

下载地址：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

### 2. 导入项目

1. 打开微信开发者工具
2. 点击"导入项目"
3. 选择 `miniapp` 目录
4. 填写 AppID（测试可以使用测试号）
5. 点击"导入"

### 3. 开发环境配置

在微信开发者工具中：
1. 点击右上角"详情"
2. 勾选"不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"
3. 这样可以在开发时使用 HTTP 和 IP 地址

### 4. 真机调试

1. 点击工具栏的"预览"
2. 扫描二维码
3. 在手机上测试

**注意**：真机调试时，如果使用 HTTP，需要在手机微信中开启调试模式。

## 发布

### 1. 配置 HTTPS

小程序正式版必须使用 HTTPS，参考后端 `DEPLOYMENT.md` 配置 SSL 证书。

### 2. 配置服务器域名

在微信公众平台配置你的 HTTPS 域名。

### 3. 上传代码

1. 在微信开发者工具中点击"上传"
2. 填写版本号和备注
3. 点击"上传"

### 4. 提交审核

1. 登录微信公众平台
2. 进入"版本管理"
3. 找到刚上传的版本
4. 点击"提交审核"
5. 填写审核信息
6. 等待审核（通常 1-7 天）

### 5. 发布

审核通过后，点击"发布"即可上线。

## 常见问题

### 1. 请求失败

**检查**：
- 服务器是否正常运行
- 防火墙是否开放端口
- 域名是否配置正确
- 是否勾选"不校验合法域名"（开发环境）

### 2. 真机无法访问

**解决方案**：
- 使用 HTTPS
- 或在微信中开启调试模式（扫码 → 右上角 → 打开调试）

### 3. 任务一直处理中

**检查**：
- 后端服务器是否正常
- 查看后端日志：`docker-compose logs -f`
- OpenClaw 是否正常工作
